# Proskurnin TV

Локальный лаунчер Android TV для телевизора SDX-43U4123B (Android 9 / API 28, m7332): приложения, погода, курсы, YouTube, подбор фильмов и голосовой AI. Отдельный веб-пульт работает в домашней сети.

Это исходники проекта для конкретного телевизора, **не универсальная прошивка**. Дампы, образы прошивки, ключи подписи, личные данные и ключи API здесь отсутствуют. Скрипты работы с разделами и загрузчиком сохранены как история исследования; запускать их на другом устройстве нельзя без независимой проверки совместимости и восстановления.

## Сборка

Нужны Python 3, JDK с javac, Android SDK Platform 33 и Build Tools 35.0.0. `ANDROID_SDK_ROOT` и `JAVA_HOME` можно переопределить; на Mac используются стандартные пути пользователя.

```sh
python3 scripts/build-proskurnin-preview.py
python3 scripts/build-proskurnin-remote.py
```

Сборка не устанавливает приложения. Первый запуск создаёт локальный ключ подписи лаунчера; пульт подписывается им же. Ключ нельзя коммитить. Обновление существующей установки требует исходного ключа. Для своей сборки необходимо заменить закреплённый SHA256 сертификата в InputBridge.java, иначе помощник справедливо отклонит команды.

API требуют отдельного развёртывания. Шаблоны: `api-keys.example.env`, `config.example.json`. Параметры `direct/ru/us` задают маршрут только конкретного API. Файлы ключей и OAuth никогда не встраиваются в APK. Скрипты развёртывания содержат параметры исходной инфраструктуры: проверьте и адаптируйте их перед использованием.

HTTPS-пульт использует сертификат локального центра, созданный `scripts/prepare-remote-tls.py --ip <адрес-ТВ>` (нужен Python cryptography). Закрытый ключ центра остаётся на компьютере. На телефоне требуется ручное доверие сертификату. Нет публичного сервера пульта и проброса порта.

Библиотека QR Code generator Nayuki распространяется на условиях MIT; текст лицензии сохранён в исходниках. Права на сторонние марки, материалы заставок и приложения принадлежат их владельцам; сторонние APK и видео не распространяются в этом репозитории.

## Проверки

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/check-publish.py
```

`tests/RatesSparklineTest.java` проверяет рост/падение/ровный ряд/пропуски. Скрипты `tests/manual_remote_*.py --live` — ручные интеграционные проверки с настоящим ТВ, ADB, Playwright и тестовыми аудио/приложением. Они меняют текущий экран и создают тестовое сопряжение; не запускать автоматически в CI. Пути SDK/браузера и адрес ТВ нужно адаптировать. Синтетическая запись проверяет транспорт и API, но не заменяет физический тест микрофона телефона.
