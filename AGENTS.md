# Proskurnin TV — правила работы

- Перед работой прочитайте README.md, CHANGELOG.md и ROADMAP.md.
- Каждое обновление лаунчера получает новую versionName/versionCode в AndroidManifest.xml и запись в CHANGELOG.md: дата, изменения, проверки, ограничения, откат. Пульт имеет отдельную версию; указывайте её явно.
- Дата установки в интерфейсе берётся из PackageInfo.lastUpdateTime, а не из времени сборки или текущего запуска.
- ROADMAP.md — единый список будущих работ. Переносите сделанное в историю, сохраняйте незавершённые проверки. Не объявляйте физические тесты выполненными по эмуляции.
- Все дальнейшие общие доработки готовьте для обоих ТВ: Sber SDX-43U4123B (последний IP192.168.18.247) и Xiaomi MiTV-MSSP1/nino (192.168.18.144). Для каждого выпуска фиксируйте отдельно сборку, установку, проверки и откат обоих профилей. Не объявляйте обновление завершённым на двух ТВ, если один недоступен. Перед каждым действием сверяйте модель/IP. Аппаратно зависимые изменения (питание, bootlogo, загрузчик, root, кнопки) реализуйте отдельными адаптерами; разрешение обновлять оба лаунчера не разрешает перенос разделов/заставок Sber на Xiaomi или несогласованную перепрошивку/перезагрузку.
- Перед изменениями ТВ сначала диагностика только чтением и локальный снимок исходного состояния. Не перезагружайте, не прошивайте и не изменяйте загрузчик без отдельного согласования. Не отключайте системные пакеты ради обхода ошибки.
- API-маршруты относятся только к API лаунчера. Они не управляют Happ, общим VPN или трафиком сторонних приложений.
- Не включайте ключи, OAuth-токены, пары телефонов, сертификаты с закрытым ключом, дампы и личные журналы в APK/Git. Секреты находятся в игнорируемых private-каталогах. Проверяйте индекс перед каждым push.
- .gitignore намеренно разрешает только исходники. Новые каталоги добавляйте точечно. Исторические прошивочные скрипты не являются инструкцией для других моделей ТВ.
- Не стирайте сопряжения пользователя во время тестов. Не логируйте распознанную речь, текст полей и содержимое паролей. Пульт доступен только в локальной сети, голос и ввод — по HTTPS.
- Фон, погода, курсы и сеть не должны блокировать главный поток UI; тяжёлые задачи останавливаются при уходе с экрана. Сохраняйте управление стрелками, OK, Back и Home.
- Для изменения выполняйте подходящие проверки и сборку, затем обновляйте журнал. Нет необходимости повторять все аппаратные тесты для небольшой правки.
- Сайт https://tv.proskurnin.com/ собирается из `site/`, `docs/screenshots/` и CHANGELOG (docs/SITE.md) и выкладывается из `main` автоматически. Видимая новая возможность — поправить плитки сайта на двух языках. На сайт не попадают адреса домашней сети, маршруты API и личные данные.
- Xiaomi nino: для согласованного короткого Home → Proskurnin и удержания → Google сохраняйте Google Home и его рекомендации включёнными. В Universal1.40.1 используется отдельная HomeKeyService без чтения содержимого окон; обычная перепривязка службы в той же загрузке не должна открывать лаунчер поверх фильма. Текущее облегчение, подтверждения и возврат — docs/XIAOMI_CLEAN_SYSTEM.md; не переносите промежуточное отключение Google из раннего этапа как окончательный план.

- Переносимый выпуск собирайте только `scripts/package-universal.py`: allowlist, тесты, SHA256 и проверка секретов. Руководство — docs/UNIVERSAL.md; матрица реализованных/зависимых функций — docs/UNIVERSAL_FEATURES.md. Не включайте исторические установщики прошивки в универсальный комплект. Не объявляйте сборку аппаратно проверенной без отдельного протокола.

- Xiaomi5925: DUMP не открыл cpuinfo обычному приложению; не повторять этот неудачный путь и не выдавать ядра/CPU одного приложения за общую утилизацию. Владелец выбрал отдельное исследование автономного запуска CPU после перезагрузки, ручной helper не активирован. Для SSID на Xiaomi согласованы ACCESS_COARSE_LOCATION и location_mode=1; позднее владелец разрешил применить доработки к Sber. Пауза Sber снята, standard1.41 установлен, DUMP отозван. На Sber для фактического включения Location дополнительно использован штатный пункт «По точкам доступа Wi-Fi»; исходные значения и возврат — docs/CPU_WIFI_STORAGE.md. Не переносить настройки Location между прошивками вслепую.

- Блик баннеров — общий renderer обоих профилей, один проход на смену фокуса, без фонового цикла. Настройка banner_shine; локальный референс PatchWall не включать в APK/публичный комплект. Реализация/проверки — docs/BANNER_SHINE.md.

- Верхние иконки и карточки валют должны иметь одинаковые бледные полупрозрачные подложки: единый PANEL_BACKGROUND=0x207f97b0 (alpha32/255), в том числе при фокусе. Выбор кнопки обозначается светлой обводкой. Плотный тёмный фон1.41 владелец отклонил; не возвращать его при переносе оформления между ТВ.

- Выпуск1.41.2: владелец отложил установку на Xiaomi («Xiaomi обновим позже»); Universal собран, не установлен. Не пытаться повторно подключать/будить Xiaomi для этого выпуска до возобновления владельцем.

- С1.41.3 круглые подложки символов валют непрозрачные (#4e6a89) по просьбе владельца; общий фон строк остаётся PANEL_BACKGROUND. Отсрочка обновления Xiaomi сохраняется и для1.41.3.

- С1.42 круги валют имеют75% непрозрачности; блик919мс по диагонали сверху слева вниз вправо. Виджет/кэш пар — CurrencyWidget/CurrencyConfig, инструкция docs/CURRENCY_WIDGET.md. Отсрочка Xiaomi сохраняется.

- 1.43 подготовлена, но владелец попросил «Пока подготовить, ТВ не трогать». Ни один ТВ не обновлять до возобновления. Двухчасовая фотосерия хранится отдельно от APK; фото Jetson Creative из reports не публиковать. Контракт — docs/BACKGROUND_PACKS.md.

- Владелец завершил сессию словами «запомни всё, позже вернёмся». Точка продолжения сохранена в конце docs/BACKGROUND_PACKS.md: только Big Sur/Golden Gate/Tahoe, смена раз в2часа, без замен/покупок;1.43 не установлена, оба ТВ пока не трогать.

- Скриншоты интерфейса для сайта сопровождаются через `docs/screenshots/catalog.json`, `manifest.json` и `scripts/capture-screenshots.py`. В этом наборе только Sber SDX-43U4123B; Xiaomi исключён. Снимки создаются исходно в 1920×1080, RGB/RGBA PNG, до3МБ, без EXIF/GPS; не кадрировать и не масштабировать. Приватные экраны маскируются только непрозрачными прямоугольниками по координатам и с причиной в каталоге. Никогда не публиковать сырые кадры с адресами, QR/кодами сопряжения, Wi-Fi, MAC, API/учётными данными, уведомлениями, историей или личными данными.
- Захват ТВ начинается с read-only проверки модели/IP/версии и локального baseline. Навигация — только стрелки, OK для открытия раздела, Back и Home; запрещено подтверждать переключатели, сохранение, удаление, сброс, сопряжение или команды питания. Режим перемещения закрывается Back (отмена). POWER никогда не отправлять из скрипта: `power-menu` открывает владелец физическим пультом, агент только снимает экран. Для пульта использовать локальную копию страницы и синтетические данные; не создавать и не удалять сопряжения. В речи/полях только строки из `syntheticInputs`; не сохранять введённое/распознанное содержимое в логах или дампах.
- Новые состояния интерфейса добавляются в каталог в той же серии сопровождения. После захвата проверять `python3 scripts/capture-screenshots.py --verify` и `python3 scripts/check-publish.py`; физическую проверку фиксировать отдельно от dry-run/рендера. При недоступности ТВ или несоответствии модели/version скрипт прекращает захват. Версии лаунчера и пульта брать из установленного Sber и манифеста сборки; набор скриншотов не повышает версии APK.
