# Proskurnin TV — правила работы

- Перед работой прочитайте README.md, CHANGELOG.md и ROADMAP.md.
- Каждое обновление лаунчера получает новую versionName/versionCode в AndroidManifest.xml и запись в CHANGELOG.md: дата, изменения, проверки, ограничения, откат. Пульт имеет отдельную версию; указывайте её явно.
- Дата установки в интерфейсе берётся из PackageInfo.lastUpdateTime, а не из времени сборки или текущего запуска.
- ROADMAP.md — единый список будущих работ. Переносите сделанное в историю, сохраняйте незавершённые проверки. Не объявляйте физические тесты выполненными по эмуляции.
- Перед изменениями ТВ сначала диагностика только чтением и локальный снимок исходного состояния. Не перезагружайте, не прошивайте и не изменяйте загрузчик без отдельного согласования. Не отключайте системные пакеты ради обхода ошибки.
- API-маршруты относятся только к API лаунчера. Они не управляют Happ, общим VPN или трафиком сторонних приложений.
- Не включайте ключи, OAuth-токены, пары телефонов, сертификаты с закрытым ключом, дампы и личные журналы в APK/Git. Секреты находятся в игнорируемых private-каталогах. Проверяйте индекс перед каждым push.
- .gitignore намеренно разрешает только исходники. Новые каталоги добавляйте точечно. Исторические прошивочные скрипты не являются инструкцией для других моделей ТВ.
- Не стирайте сопряжения пользователя во время тестов. Не логируйте распознанную речь, текст полей и содержимое паролей. Пульт доступен только в локальной сети, голос и ввод — по HTTPS.
- Фон, погода, курсы и сеть не должны блокировать главный поток UI; тяжёлые задачи останавливаются при уходе с экрана. Сохраняйте управление стрелками, OK, Back и Home.
- Для изменения выполняйте подходящие проверки и сборку, затем обновляйте журнал. Нет необходимости повторять все аппаратные тесты для небольшой правки.
