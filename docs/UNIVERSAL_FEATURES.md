# Матрица функций Universal 1.44.3

«Включено» означает наличие реализации в собранном пакете. Это не отметка о выполненном тесте на каждом телевизоре. Root не требуется для первых трёх групп.

| Плитки | TV-баннеры всех приложений, запасная иконка, скругления, тонкая рамка и подложки | Качество зависит от ресурсов APK |

## Отдельно: оборудование Sber, не универсальные функции

Белая ранняя заставка PROSKURNIN / TV SYSTEM и анимация загрузки, патчи фокуса SystemUI, root/init-автозапуск и исправления питания относятся к конкретной прошивке Sber. Документация сохранена в истории, установщики не входят в переносимый комплект. Другие модели требуют собственного исследования разделов, подписей, verified boot и восстановления. Root сам по себе не гарантирует совместимость этих изменений.

## Пока не реализовано / не подтверждено

Настоящий альтернативный 4K OSD, скачиваемые фоновые наборы, выбор города/канала/валют, эффект нового подписчика и деморежим, CRT-включение/выключение, меню со звуками, полная история всех кинотеатров, безусловный глобальный голос/клавиши на любой прошивке. Реальные физические проверки нового root-free пульта, сна/пробуждения/перезагрузки — по чек-листу. Полный актуальный план: ROADMAP.md.

## Почему не всё одинаково без root

Android даёт обычному приложению рисовать свой интерфейс, запускать доступные Activity, использовать DreamService и запрашивать SpeechRecognizer. Глобальная инъекция произвольных кнопок/перезапись загрузчика — другие права. Поэтому пакет сначала использует поддерживаемые интерфейсы; дополнительные возможности включаются отдельно, без отключения системных служб.

Первичные источники: [TV-приложения Android](https://developer.android.com/training/tv/get-started/create), [AccessibilityService](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService), [DreamService](https://developer.android.com/reference/android/service/dreams/DreamService), [TV Input](https://developer.android.com/reference/android/media/tv/TvInputManager). Наличие API не заменяет тест конкретной прошивки.
