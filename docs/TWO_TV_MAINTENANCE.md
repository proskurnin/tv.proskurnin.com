## PatchWall и очистка

На Xiaomi PatchWall уже был отключён (`enabled=3`) и не обнаруживался фоновым процессом. Его обновление продолжало занимать место. Сохранены обновлённый APK 4.21.148 и заводской 3.1.2, метаданные пакета, журналы и хеши; локальный SHA256 каждого файла совпал с ТВ.

Резерв: `backups/two-tv-maintenance-20261109/xiaomi/`. Инструкция возврата: `RESTORE.md` в этом каталоге. Это резерв установщиков/состояния, **не полный дамп и не экспорт закрытых данных**. Каталог игнорируется Git; сторонние APK не публикуются.

Выполнено только для `com.mitv.tvhome.atv`:

1. `pm uninstall -k --versionCode 148 com.mitv.tvhome.atv` — удалено обновление, возврат к заводскому APK.
2. `pm disable-user --user 0 com.mitv.tvhome.atv` и `pm uninstall -k --user 0 com.mitv.tvhome.atv` — заводская версия исключена для пользователя, данные запрошено сохранить.
3. Список пакетов до/после отличается только PatchWall. Сам `/system/priv-app/TvHome` не удалялся и место /data не занимает.

Сразу после удаления обновления свободное место выросло на 46 МиБ. Общая команда `uninstall-system-updates` намеренно не использовалась: в Android9 она затрагивает обновления всех системных приложений. Поведение проверено по исходнику AOSP `PackageManagerShellCommand` и фактическому выводу ТВ.

Также сохранён и удалён только известный временный `/data/local/tmp/ProskurninXiaomiPreview.apk`. На обоих ТВ выполнено `pm trim-caches 1073741824 internal`: штатная очистка кэшей для попытки получить 1 ГиБ свободного места. Это не `pm clear`: аккаунты, настройки, приложения, голосовые файлы и VPN-профили не удалялись. Каталог `Download/vless-keys` не читался и не изменялся. Отдельный старый Preview остаётся отключённым; данные сохранены.

Google Home и его рекомендации включены для согласованного долгого Home. Play Services, Play Store, штатные голос/TV Input/HDMI/Bluetooth и системные библиотеки не отключались.

### Возврат PatchWall

Из корня проекта, после проверки адреса/модели:

```sh
adb -s 192.168.18.144:5555 shell cmd package install-existing --user 0 com.mitv.tvhome.atv
adb -s 192.168.18.144:5555 install -r backups/two-tv-maintenance-20261109/xiaomi/com.mitv.tvhome.atv/0-base.apk
adb -s 192.168.18.144:5555 shell pm disable-user --user 0 com.mitv.tvhome.atv
```

Это возвращает прежнее отключённое состояние. Для использования PatchWall последнюю команду заменить на `pm enable --user 0 com.mitv.tvhome.atv`. В текущей сессии применяется ADB `/private/tmp/proskurnin-platform-tools-current/platform-tools/adb -P 5038`; полные команды есть в резерве. После этого удаления старый rollback очистки, который меняет только enabled-state, недостаточен для возврата PatchWall.

## CPU и незавершённое обновление Sber

На Sber исходный показатель через `/proc/stat` работал; это дополнительно подтвердил владелец. На Xiaomi этот путь закрыт. Испытанные1.40.2/1.40.3 пытались читать агрегат системной службы `cpuinfo` с DUMP, но служба недоступна процессу обычного приложения. Фактический результат1.40.3: `CPU source/status=service_unavailable`, а не успешно полученный процент.

В1.40.4 неработающий путь, subprocess и декларации DUMP/PACKAGE_USAGE_STATS удалены. Xiaomi показывает `CPU · ядер: 4`, «Настройки → Возможности телевизора» — аппаратную платформу и ABI, с явным пояснением отсутствия общего процента. Это сведения о CPU, не измерение загрузки. Отдельный системный сборщик/повышение прав не внедрялся. PACKAGE_USAGE_STATS никогда не выдавалось, appops не изменялись. DUMP на Xiaomi отозван при завершении эксперимента.

На Sber по просьбе владельца остановлены дальнейшие действия: идёт фильм. Поэтому установленная версия пока1.40.2, подготовлена standard1.40.4. Её установка и отзыв DUMP остаются отдельным незавершённым пунктом; нельзя говорить, что1.40.4 установлена на обоих ТВ. Старое чтение CPU на Sber сохраняется.

После разрешения продолжить на Sber сначала проверить модель/IP и завершение просмотра, затем отозвать ненужный диагностический доступ и установить подготовленный стандартный APK:

```sh
adb -s 192.168.18.247:5555 shell pm revoke local.proskurnin.preview android.permission.DUMP
adb -s 192.168.18.247:5555 install -r builds/proskurnin-preview-v1/ProskurninPreview.apk
```

Это план следующего шага, **не выполненные команды**. Не ставить профиль Universal поверх Sber: его системные адаптеры отличаются. Root, перезагрузка и смена Home для этого обновления не нужны.

## AI и стартовая заставка

- На обоих ТВ: первая иконка ✦ справа сверху → короткий OK открывает «Что посмотрим?», удержание OK — «Давайте поговорим». Кнопка «Голос» внутри экрана запускает прослушивание. Оба режима доступны также в настройках.
- Sber: ранее настроенная кнопка помощника — одиночное нажатие подбор+голос, двойное — диалог+голос. Её служба и настройка сохранились. Новый физический тест после 1.40.2 отдельно не выполнен.
- Xiaomi: штатная кнопка микрофона остаётся Google Assistant. Она пока не назначена нашему AI; не отключали Google и не переносили аппаратный обработчик Sber.
- Sber `/system/media/bootanimation.zip` имеет SHA256 `f13be8fb030b6c0534474a16b8f76ba16ea898f8eb83c3cf239e7d5d18e9d154` — точно как проектная v7. Смена APK не устанавливает ранний логотип. При обычном выходе из сна полной загрузочной последовательности может не быть.
- Xiaomi сохраняет штатный bootanimation. `/system/media/bootanimation.zip` читается, `/data/local` закрыт для shell; путь записи без изменения защищённой системы не подтверждён. PROSKURNIN как реальная загрузочная заставка требует отдельного решения и проверяемого восстановления. Разделы, root, загрузчик и питание в этом этапе не менялись.
