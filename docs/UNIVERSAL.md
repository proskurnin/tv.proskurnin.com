# Proskurnin TV Universal 1.40.1

Переносимый комплект Android TV / Google TV: лаунчер 1.40.1 (code 55), пульт с телефона 1.2 (code 4), необязательный ADB-помощник, исходники и API-сервер. **Это приложения, не прошивка. Root для установки и основных функций не нужен.** На телевизорах с Tizen, webOS и Vidaa этот APK не работает.

Состояние выпуска:1.40.1 собран и установлен на Xiaomi Android9. Владелец подтвердил короткое/долгое Home, на ТВ проверены погода Москвы, YouTube и AI-подбор с постерами. После одного согласованного перезапуска владелец подтвердил автозапуск, оба жеста Home и штатный микрофон. Полный чек-лист HDMI/AI-голоса/телефонного пульта/сна ещё не закрыт. Прежние версии проверялись на Sber;1.40.1 туда не устанавливался. Совместимость с другими моделями требует проверки.

## Состав архива

- `apks/ProskurninUniversal.apk` — главный экран, приложения, AI-подбор и диалог, YouTube, погода, курсы, фоны, стандартная служба заставки. AI-экраны входят в этот APK, это не отдельные приложения.
- `apks/ProskurninRemote.apk` — локальный веб-пульт, сопряжение, ввод текста и голос с телефона.
- `optional/input-bridge.jar` — ограниченный помощник клавиш от пользователя ADB shell; не обязателен, не root, не системный APK.
- `source/` — поддерживаемые исходники, сборка, сервер, тесты, история и документация. Исторические прошивочные установщики в комплект не включены.
- `MANIFEST.json`, `SHA256SUMS`, `BUILD-INFO.txt` — состав, размеры, версии, подписи и результаты проверок сборки.
- Сторонние кинотеатры не встроены внутрь нашего APK. Каталог и источники — [UNIVERSAL_APPS.md](UNIVERSAL_APPS.md).

В архиве нет ключей API, токенов телевизоров, аккаунтов, сертификатов с закрытым ключом, сетевых пар телефонов, дампов или подписывающего keystore. На другом ТВ потребуется свой доступ к API и новое сопряжение телефона. APK подписаны локальным ключом проекта; не предназначены для публикации в Google Play без отдельной подготовки релиза.

## Требования

Android 9 / API 28 или новее; управление D-pad; стандартные Android PackageManager и Activity. APK содержат Java/Dex без нативных библиотек: отдельные ARMv7/ARM64/x86 сборки нашего приложения не нужны. Архитектура сторонних APK проверяется отдельно.

Практический ориентир — ТВ с 2 ГБ RAM и аппаратным H.264, не гарантированный минимальный объём. Проверять память на конкретной модели. Интерфейс использует базовый макет 1920×1080 и масштабируется в системное окно; 4K-панель не означает настоящий 4K-рендеринг Android. Пакет не меняет разрешение/density.

Для двух приложений оставьте около 60 МБ свободного места с запасом на установку и кэши; для видеозаставки дополнительно до 300 МБ и сохраняемый свободный резерв 256 МиБ. Это запас для развёртывания, не измеренный размер установленного приложения. Заставка выключается отдельно, ролики не обязательны.

## Безопасная установка

1. На новом ТВ сначала снять только чтением: Android/API, ABI, RAM/место, текущий Home, DreamService, VoiceInteractionService, HDMI/Live TV, пульт и Bluetooth. Записать эти компоненты локально. Не переносить настройки Sber.
2. Проверить `SHA256SUMS` из корня распакованного архива: `shasum -a 256 -c SHA256SUMS` (Linux: `sha256sum -c SHA256SUMS`). Сверить подпись через `apksigner verify --print-certs`.
3. Установить APK обычным способом либо явно через ADB. Комплект сам ничего не устанавливает. На экране ТВ подтвердить доверие своему компьютеру.

```sh
adb connect TV_IP:5555
adb -s TV_IP:5555 get-state
adb -s TV_IP:5555 install -r apks/ProskurninUniversal.apk
adb -s TV_IP:5555 install -r apks/ProskurninRemote.apk
adb -s TV_IP:5555 shell am start -n local.proskurnin.preview/.MainActivity
```

`TV_IP` — заменить адресом нужного телевизора. При `offline`, отказе авторизации/производителя или таймауте остановиться. Не использовать root, отключение пакетов и повторную установку вслепую.

**Идентификатор лаунчера — `local.proskurnin.preview`**, историческое имя. Universal обновляет имеющийся полноценный Proskurnin TV с той же подписью; это не отдельный Preview. Xiaomi Preview (`local.proskurnin.xiaomipreview`) остаётся отдельным. До замены полноценной установки сохранить предыдущий APK и записать настройки. Universal выключает резервный автозапуск и собственное меню питания; ранее установленные внешние системные модули сам не удаляет. Для Sber переход с системными модулями проводить отдельно, не считать обычное обновление APK их откатом.

В Universal нет BOOT_RECEIVER и Activity собственного системного меню питания. Home зарегистрирован как обычный кандидат: прошивка может показать выбор, но программа не назначает себя автоматически. Отдельно включаемая служба Home в1.40.1 умеет перенаправлять штатный Home в наш и открывать штатный экран по удержанию. Она запускает наш экран один раз при первой активации/новом boot_count; обычная перепривязка в той же загрузке не прерывает другое приложение. Метаданные смены окна используются только для штатного Home, доступ к содержимому окон отсутствует. До включения этой службы такой обработки нет. На прошивке с принудительным штатным Home возможно краткое появление его окна перед перенаправлением; отсутствие этого эффекта проверяется на реальном старте.

## Первое включение

- Все запускаемые приложения обнаруживаются автоматически. Вниз из главного ряда — общий список, долгий OK — вспомогательное меню. Шесть мест на главном экране, перестановки, замена, папка «Прочее» и сортировка сохраняются локально. Отсутствующие сервисы Android не выдаются за запускаемые приложения.
- Шестерёнка → «Возможности телевизора» показывает найденные службы речи, TV Input и настройки заставки. Наличие службы не доказывает работу микрофона/HDMI — нужна проверка.
- Шестерёнка → «Подключение API»: HTTPS-адрес `/tv-api/v1/` и **два токена устройства**, не ключи поставщиков. Альтернатива — защищённый импорт ниже.
- Погода по умолчанию для Москвы. Без серверной конфигурации используется прямой Open-Meteo, затем wttr.in. После подключения сервера — серверный маршрут каждого поставщика с прямым резервом. Изменение города пока не реализовано.
- Голос внутри AI просит обычное разрешение микрофона. Аппаратный помощник не переназначается при установке. Его перехват и обучаемые кнопки требуют ручного включения службы доступности и отдельной проверки.
- Если всё работает: «Выбор главного экрана Android» → Proskurnin TV. Если производитель запрещает смену Home, оставить обычным приложением. Не отключать штатный лаунчер.
- «Открыть другой Home» выбирает доступный сторонний Home с наибольшим приоритетом; служебный FallbackHome исключён. Долгий Home требует включённой службы «Proskurnin TV — кнопка Home» и поддержки прошивки. Google Home при этом должен оставаться включённым. Для отключения перенаправления и обработки кнопки выключить только эту службу в Android → Специальные возможности.

## Импорт API без root

Подготовка сервера описана в [UNIVERSAL_SERVER.md](UNIVERSAL_SERVER.md). Файл `device.json` содержит только адрес и два отдельных токена ТВ. Не хранить в общей папке загрузок ТВ.

```sh
cd source
chmod 600 /PRIVATE/PATH/device.json
python3 scripts/provision-universal.py --device TV_IP:5555 --config /PRIVATE/PATH/device.json
python3 scripts/provision-universal.py --device TV_IP:5555 --config /PRIVATE/PATH/device.json --remote
```

Скрипт передаёт данные по stdin уже авторизованного ADB; токенов нет в аргументах процессов/журналах. Provider допускает только UID 2000 и системное разрешение DUMP; пишет только собственное закрытое хранилище приложения. Не даёт shell, произвольных путей или смены системных настроек. Нужен ADB в PATH либо `--adb /путь/adb`. При запрете DUMP остановиться; API лаунчера можно ввести в его настройках, для удалённого голоса этот импорт тогда недоступен.

## Пульт без root

Открыть «Пульт с телефона», включить сервер, отсканировать QR, ввести короткий код и подтвердить телефон на ТВ. Проброс портов запрещён: сервер слушает только выбранный частный IPv4 интерфейс Wi-Fi/LAN, клиенты — из той же подсети. Во сне сервер закрывается. Для другого IP открыть новый QR; ранее спаренный телефон не стирается.

Уровни управления:

1. Без специальных разрешений: главный экран нашего лаунчера, открытие приложений, Home в наш лаунчер, громкость.
2. Служба «Пульт · ввод в активное поле»: Back, фокус/OK в приложениях с доступным деревом элементов, обычные текстовые поля. Пароли и неподдерживаемые поля не передаются. Ввод текстов и голос доступны только по HTTPS. Доступность включается человеком в Android.
3. Необязательный `input-bridge.jar`: более полный D-pad/OK/Back/Menu/Play из shell. Никаких координат, Power, произвольных команд или ввода секретов. Только наш APK с совпадающей подписью. На некоторых прошивках доступ запрещён; запрет не обходить.

```sh
adb -s TV_IP:5555 push optional/input-bridge.jar /data/local/tmp/proskurnin-input-bridge.jar
adb -s TV_IP:5555 shell 'CLASSPATH=/data/local/tmp/proskurnin-input-bridge.jar app_process /system/bin local.proskurnin.remote.InputBridge'
```

Последняя команда работает в переднем плане; держите терминал открытым. Остановить Ctrl+C. После завершения процесса/перезагрузки ТВ потребуется повторный запуск. При остановке терминала убедиться, что процесс завершился (`pidof app_process` недостаточно: там могут быть чужие процессы); не убивать все app_process. Нет автоматической установки init/root-службы. Можно просто выключить веб-пульт: команды больше не принимаются независимо от живого bridge.

## HTTPS и микрофон телефона

В `source/` создать отдельное Python-окружение, установить `cryptography>=43`, запустить:

```sh
python3 scripts/prepare-remote-tls.py --ip TV_IP
python3 scripts/provision-universal.py --device TV_IP:5555 --config /PRIVATE/PATH/device.json --remote --remote-tls integrations/remote/private
```

Скрипт TLS создаёт локальный CA и сертификат IP на компьютере, не устанавливает их автоматически. Весь каталог `private` — только владельцу, не в Git/архив. После импорта выключить/включить **сервер пульта** его кнопкой (не телевизор), чтобы загрузить сертификат. На телефоне доверять только своему CA, сверив SHA256 из вывода генератора. iPhone: `http://TV_IP:8765/remote-ca.mobileconfig`, установка профиля, затем включение полного доверия в «Об этом устройстве → Доверие сертификатам». Android: `http://TV_IP:8765/ca.cer`, пользовательский CA согласно настройкам производителя. После доверия открыть `https://TV_IP:8766/` и заново сопрячь HTTPS-сеанс.

Закрепить адрес DHCP для ТВ. При смене IP перевыпустить сертификат и импортировать его; старый CA повторно используется, если его закрытый ключ сохранён. CA не является VPN и не перехватывает интернет. На чужом телефоне не устанавливать без согласия владельца. Реальные HTTPS/микрофон iPhone и Android ещё требуют аппаратной проверки.

## Выключение функций и откат

- Фон: «Фон лаунчера → Изображение → выкл»; там же сброс оформления фона.
- YouTube, графики, AI-значок, VPN-значок: соответствующие выключатели в настройках. VPN-профиль не удаляется; в Universal кнопка открывает Happ/системные настройки и показывает фактическое состояние, не обещает переключение любого VPN.
- Кнопки: отключить наши службы Home/помощника в специальных возможностях; исходные голосовые пакеты не отключаются.
- Заставка: Android → Заставка → ранее записанный компонент; отключить обновление/кэш в приложении. Точное возобновление позиции видео зависит от кинотеатра.
- Пульт: «Сервер → выключить», «Забыть все телефоны», отключить его службу доступности. Для полной очистки удалить только `local.proskurnin.remote`; на телефоне удалить профиль/CA и данные сайта.
- Лаунчер: выбрать прежний Home в Android, затем удалить только `local.proskurnin.preview`, если данные не нужны. Сторонние приложения сохраняются. Для возврата предыдущей версии без потери данных требуется та же подпись и разрешённый Android номер версии: установка меньшего versionCode обычно запрещена; надёжный путь — сборка прежнего кода с увеличенным code. Удаление с последующей установкой удаляет настройки — не выполнять автоматически.
- Отозвать API-доступ: удалить соответствующий hash из карты устройств сервера, перезапустить только backend. Для созданного комплектом первого устройства удалить `tv-primary` из обеих карт; при повторном подключении выдать новые токены. Очистка данных/удаление нашего приложения удаляет его локальные токены. Provider-ключи отзываются отдельно в кабинете поставщика.

## Проверка перед использованием как Home

[Матрица функций](UNIVERSAL_FEATURES.md) и [чек-лист устройства](UNIVERSAL_TESTING.md) отделяют локальные проверки от реального ТВ. Не менять Home до проверки пульта, HDMI/Live TV, звука, Bluetooth и прежнего голосового помощника. Полностью идентичная работа системных функций на любых ТВ невозможна без поддержки производителя; приложение не пытается обходить ограничения.
