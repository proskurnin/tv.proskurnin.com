# Диагностика фокуса меню питания — 2026-11-08

Статус: **не исправлено и не подтверждено физическим пультом**. Не считать наличие модуля успешной проверкой.

Подтверждено: ActionsDialog SystemUI открывается по долгому питанию. Фокус в UI-дереве находится на полноэкранной подложке. ADB TAB переносит его на «Выключить», затем ADB Down/Up меняют пункт. Физические стрелки поступают в систему, но пользователь несколько раз сообщил, что выделение не перемещается. Повторное открытие меню снова фокусирует подложку. Код наших служб не перехватывает стрелки.

Гипотеза: участвует выбор подложки в стандартном обходе фокуса; одного временного TAB недостаточно. Отличие обработки физических событий требует проверки. Исследованы фактические ресурсы и код SystemUI этого ТВ. Модуль `local.proskurnin.powerfocus` меняет `descendantFocusability` корня и списка на `afterDescendants`. Он не меняет обработчики выключения, перезагрузки и скриншота.

`/vendor/overlay/ProskurninPowerFocus.apk` размещён отдельным файлом, до операции его не существовало. SHA256 размещённого файла: `26f1c62fef6826c0153ff764d18ae9fed3b52a72ab248247faa9952cf1ee4f63`. Активация ожидает следующую загрузку; перезагрузка не выполнялась. Обычная установка overlay была отклонена требованием платформенной подписи. Исходный `/vendor/overlay/ProskurninPowerMenu.apk`, включающий меню долгого питания, сохранён.

После согласованного включения: проверить загрузку SystemUI и состояние overlay, открыть меню, проверить реальным пультом Down/Up, края списка, повторное открытие и Back. Не отправлять OK на выключение/перезагрузку во время проверки без согласия пользователя. Если проблема остаётся, исследовать доставку событий отдельно; не объявлять её решённой по ADB.

## Откат только нового модуля

Требует root ADB этой прошивки и доступного для записи vendor. Команды выполняются с актуальным адресом ТВ, не автоматически:

```sh
adb -s TV_IP:5555 root
adb -s TV_IP:5555 wait-for-device
adb -s TV_IP:5555 shell 'mkdir -p /data/local/tmp/proskurnin-rollback && mv /vendor/overlay/ProskurninPowerFocus.apk /data/local/tmp/proskurnin-rollback/ProskurninPowerFocus.apk && sync'
adb -s TV_IP:5555 unroot
```

Затем требуется отдельно согласованная перезагрузка. Не удалять `ProskurninPowerMenu.apk`. После смены режима ADB проверить локальный помощник веб-пульта: ручной процесс может завершиться вместе с ADB. Ресурсный модуль привязан к SystemUI данного телевизора и не предназначен для установки на Xiaomi.
