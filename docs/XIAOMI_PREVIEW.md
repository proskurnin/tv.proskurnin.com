## Сборка и состав

```sh
python3 scripts/build-proskurnin-preview.py --profile xiaomi-preview
```

Архив установленного выпуска: `reports/xiaomi-preview-v1391/ProskurninXiaomiPreview-1.39.1.apk`, версия **1.39.1-xiaomi-preview / 52**, package **local.proskurnin.xiaomipreview**, размер **5 793 533 байта**.

SHA256 подготовленного файла:

```text
67a0520738f22926ff85ea238fbafec33c75d53a731854075d0e56f5fb74f3fd
```

Пересборка может изменить байты и подпись контейнера APK; перед установкой сверять хэш конкретного согласованного артефакта. Он сохранён в `reports/xiaomi-preview-v1391/artifact.json`; подпись и разобранный бинарный manifest — рядом.

Из стандартных исходников формируется отдельный manifest: одна MainActivity с LAUNCHER/LEANBACK_LAUNCHER; нет HOME, BOOT_COMPLETED, служб Accessibility/Dream и любых приёмников. Разрешения: INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE. У приложения нет разрешения на микрофон и автоматический старт при загрузке. `allowBackup=false`. Служебные Java-классы могут находиться в общем dex, но не объявлены как компоненты и недоступны настройкам этого профиля.

Обычная сборка без `--profile` сохраняет прежние компоненты и package; её **не использовать для этого предпросмотра**. Никаких скриптов установки/изменения прошивки в сборщике нет.

## Что доступно

- Интерфейс Full HD, часы, статичные фоны и их настройки, курсы и графики.
- Погода Москвы напрямую через Open-Meteo → wttr.in; если источники недоступны, показывается штатная ошибка/кэш с датой. Серверные ключи и настройки маршрутизации Sber не переносились.
- Избранные из установленных приложений, включая Okko `ru.more.play` и SmartTube Beta; общий список, перестановки, «Прочее», баннеры.
- Источники через зарегистрированные TV Input и стандартные URI, отдельный Live TV. Реальный переход/сигнал ещё не проверен; недоступный экран не открывается через обходы.
- Настройки предпросмотра и выход в текущий системный Home.

AI, YouTube-счётчик, управление VPN, веб-пульт, перехват кнопок, видеокэш и системная заставка не включены в доступные функции этого этапа. Самостоятельные установленные приложения остаются в общем списке, включая VPN и YouTube/SmartTube. Пользователь может запускать их как раньше.

## Установка и результаты

Перед установкой проверены модель MiTV-MSSP1 и доступность ADB, сохранены свежие Home, Dream, voice, recognition, accessibility, disabled-packages, полный список пакетов и свободное место (667 МиБ). Предпросмотр ранее отсутствовал. Закрытый vendor keylayout не читался, root не использовался.

Выполнены команды (полный путь SDK ADB и журнал — в локальном отчёте):

```sh
adb -s 192.168.18.144:5555 install builds/proskurnin-preview-v1/ProskurninXiaomiPreview.apk
adb -s 192.168.18.144:5555 shell am start -n local.proskurnin.xiaomipreview/local.proskurnin.preview.MainActivity
```

Первый вызов install не вернул результат за 35 секунд. Повторной установки не было: чтение PackageManager подтвердило установленный package, versionCode 52 и versionName 1.39.1-xiaomi-preview. Затем `am start -W` вернул Status ok, TotalTime 2613 мс. Пользователь подтвердил: предпросмотр открыт и реагирует на физический пульт.

При попытке получить снимок и память ADB перешёл в offline. Проверки остановлены. Скриншот и PSS получить не удалось; команды навигации не выполнялись. Нельзя утверждать причину обрыва или полную совместимость по одному успешному запуску. Никакого `set-home-activity`, `settings put`, `pm disable`, `pm clear`, reboot или системных помощников не выполнялось.

Осталось проверить после восстановления связи: Home остаётся Google; все 24 пользовательских приложения доступны в общем списке; стрелки/OK/Back/долгий OK, перестановки и «Прочее»; RAM/отрисовку/ошибки; запуск выбранных пользователем приложений и возврат в Preview. HDMI, Live TV и голос физическим пультом проверять отдельно, не выдавать эмуляцию ADB за физическую проверку. Сон/перезапуск — только в отдельно согласованное время. После теста сравнить исходные системные значения.

## Выход и удаление

Нажать **Home** — штатный главный экран; **Back** из основного ряда — выйти из Activity. В настройках Preview есть «Открыть штатный главный экран». Для повторного открытия выбрать **Proskurnin TV · Preview** в обычном списке приложений.

Полный откат предпросмотра: Android → Настройки → Приложения → Proskurnin TV · Preview → Удалить. Альтернатива:

```sh
adb -s 192.168.18.144:5555 uninstall local.proskurnin.xiaomipreview
```

Удалится только отдельное приложение и его настройки расположения/кэш. Не использовать имя `local.proskurnin.preview` из старого отчёта: для текущей подготовки выбран новый изолированный package. Не очищать данные других приложений, не менять Home и не восстанавливать чужие дампы.
