# Пульт с телефона 1.1

Открывается из настроек Proskurnin TV → «Пульт с телефона». Работает только в одной домашней сети; порт в интернет не пробрасывается. При выключении сервера оба слушателя закрываются. Сон выключает сервер; разбудить ТВ по этому соединению нельзя.

## HTTPS и микрофон

На исходном телевизоре: `https://192.168.178.105:8766/`. Старый `http://192.168.178.105:8765/` сохраняет кнопки и старые сопряжения, но голос/текст требуют HTTPS. Новому адресу нужно отдельное сопряжение с подтверждением на ТВ.

iPhone (Safari):

1. Открыть `http://192.168.178.105:8765/remote-ca.mobileconfig`, разрешить загрузку профиля.
2. Настройки → Основные → VPN и управление устройством → Proskurnin TV → Установить.
3. Основные → Об этом устройстве → Доверие сертификатам → включить Proskurnin TV Local Remote CA.
4. Открыть HTTPS-адрес и выполнить сопряжение. Нажать «Голос», разрешить микрофон.

Это локальный центр сертификатов, а не VPN/прокси. Доверяйте только центру, отпечаток которого сверили с `integrations/remote/private/fingerprint.txt` на своём компьютере. Ключ центра остаётся на компьютере и не отправляется на ТВ/сервер. Сертификат ТВ действует год и привязан к IP; закрепите IP в DHCP роутера. При его смене перевыпустите сертификат.

Android: скачать `http://<IP-ТВ>:8765/ca.cer` и установить как сертификат CA в настройках безопасности (названия зависят от производителя). Открыть HTTPS в Chrome. Реальная проверка Android-телефона ещё требуется.

Микрофон браузера требует доверенного [защищённого контекста](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia). Ошибку сертификата нельзя считать корректной настройкой HTTPS.

## Голос

«Голос» записывает микрофон **телефона**, до 30 секунд и 750 КБ. «Завершить» отправляет запись на API для распознавания; затем можно исправить текст и нажать «Отправить на ТВ». Режимы: «Поговорим», «Найти фильм», «В поле ТВ». Для поля сохраняется его идентификатор: после перехода на другое поле фраза туда автоматически не попадёт.

Маршрут записи: телефон → локальный HTTPS ТВ → API-шлюз RU → существующий туннель к US → OpenAI. Аудио отправляется только по нажатию. Наши приложения не записывают аудио/транскрипт на диск и не логируют содержимое. Политика хранения самого провайдера определяется условиями API. Ключ находится только на сервере. Используется [Audio Transcriptions API](https://developers.openai.com/api/docs/guides/speech-to-text); модель задаётся серверным `transcription_model` (по умолчанию gpt-4o-mini-transcribe). Лимит 100 распознаваний в сутки, один активный запрос, размер и MIME проверяются. Учитывать объявленные провайдером сроки поддержки модели.

При уходе со страницы запись прекращается и отбрасывается; уже отправленный API-запрос может закончиться на сервере. Повторной автоматической отправки нет.

## Клавиатура

Когда на ТВ выбран обычный редактируемый элемент, в HTTPS-пульте появляется «Текст на телевизоре». Нажмите поле на телефоне — откроется его клавиатура. Ввод передаётся после короткой паузы; можно использовать системную диктовку клавиатуры телефона.

Служба `local.proskurnin.remote/.TextInputService` использует [ACTION_SET_TEXT](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo.AccessibilityAction#ACTION_SET_TEXT) только для активного узла. Проверяет пароль, тип поля, окно/узел и ревизию текста. Пароли скрыты, текст длиннее 512 символов не передаётся. Настройка «Ввод текста с телефона» выключает функцию без удаления сопряжений. Для полного отзыва разрешения отключить «Пульт · ввод в активное поле» в специальных возможностях.

Некоторые приложения рисуют поиск сами или не предоставляют ACTION_SET_TEXT. В них автоматический перехват не обещается; кнопки пульта продолжают работать. При конфликте ввода с другим телефоном/ТВ нужно нажать «Обновить поле с ТВ».

## Отключение и откат

- Пульт с телефона → «Сервер: включён · выключить» закрывает HTTP и HTTPS, прекращает отслеживание полей. Сопряжения сохраняются.
- «Забыть все телефоны» отзывает все сессии; «Забыть этот телефон» — текущую.
- В iPhone удалить профиль Proskurnin TV в VPN и управлении устройством; на Android удалить соответствующий пользовательский CA.
- Чтобы убрать ввод, выключить только TextInputService, сохранив VoiceKeyService лаунчера. Не очищать весь список accessibility-служб.
- Для возврата приложения: локальные резервные APK до обновления лежат в `reports/release-v131/before/` на исходном Mac. Downgrade может потребовать поддерживаемую устройством установку с `-d`; не удалять приложение, если нужно сохранить настройки/сопряжения. Безопаснее пересобрать старые исходники с большим versionCode и тем же ключом.
- Для удаления системного помощника существует `scripts/remove-proskurnin-remote-helper.py --remove-helper`; это отдельное действие владельца. Оно удаляет только два файла помощника, не профиль VPN или голосовой ассистент.
- API-откат текущего выпуска: резервные пути сохранены в локальном `reports/release-v131/backend.json`; вернуть api_relay.py/us_api_worker.py и nginx.conf, проверить nginx, перезапустить только два API-сервиса и reload nginx. Ключи не менялись.

## Статус проверок

Кнопки на реальном iPhone подтверждены для 1.0. Проверку доверия сертификату и реального микрофона iPhone для 1.1 пользователь отложил. Сон/пробуждение и перезагрузка также остаются в ROADMAP.md. Автоматические тесты не заменяют эти проверки.
