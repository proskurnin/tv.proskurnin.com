# Сайт https://tv.proskurnin.com/

Витрина проекта: что умеет лаунчер, пульт с телефона, как он делался, границы и планы. Не инструкция по установке: сборка привязана к одному ТВ (см. README).

## Устройство

- `site/` — исходники: `index.html` (тексты на русском), `assets/style.css`, `assets/app.js` (английский перевод, фон и часы, снимки, окно подробностей, навигация стрелками), `favicon.svg`, `robots.txt`, `sitemap.xml`. Без фреймворков и CDN.
- `scripts/build-site.py` → `dist/site/` (игнорируется Git). Сборщик:
  - берёт снимки из `docs/screenshots/manifest.json` (docs/SCREENSHOTS.md) и делает WebP полного размера и уменьшенный; экраны без снимка показываются пустой рамкой «Снимок экрана появится скоро». Манифест читается в обоих видах: список `screens: [{id, …}]` (ТЗ, 7.2) и словарь `screens: {id: {…}}` (пишет `capture-screenshots.py`); подписи берутся из `catalog.json`. Снимки пульта (`remote-*`), снятые в широком окне, для сайта обрезаются по центру до пропорции телефона 390:844, PNG в `docs/screenshots/` не меняются;
  - собирает журнал выпусков и цифры (число выпусков, дни, версии лаунчера и пульта) из `CHANGELOG.md` и `AndroidManifest.xml`;
  - фон — набор «Горы и озёра» из лаунчера, по тем же часам периодов (6/11/17/22) по времени посетителя; авторы и лицензии CC BY / CC BY-SA берутся из `CREDITS.txt` и выводятся в подвале;
  - добавляет хеш содержимого к именам файлов в `assets/` (Apache отдаёт их как immutable) и встраивает данные в `index.html`.
- Нужен Pillow: `python3 -m venv .venv && .venv/bin/pip install Pillow==11.0.0 && .venv/bin/python scripts/build-site.py`. Проверка: `python3 -m unittest discover -s tests -p 'test_build_site.py'`. Просмотр: `python3 -m http.server -d dist/site 8000`.

## Языки

Русский по умолчанию. Порядок выбора: сохранённый переключатель (RU/EN) → `#en` / `#ru` в адресе → браузер (английский, только если среди языков браузера есть английский и нет русского) → русский. Тексты журнала выпусков остаются на русском.

## Управление

Как на ТВ: стрелки переводят фокус между плитками, ссылками и карточками выпусков, Enter открывает подробности, Esc или Backspace закрывает. Мышь и касание работают как обычно.

## Выкладка

`.github/workflows/site.yml`: pull request — тесты и сборка; push в `main` с изменениями сайта, снимков, CHANGELOG, версий или фонов — ещё и выкладка. Архив `site/` уходит пользователю `tv-deploy@80.87.199.223`; его ключ может выполнить только `deploy <sha> <run>` (forced command `travel-site-ci-entry tv`, общий инструмент сайтов на сервере `travel-site-deploy`: распаковка, атомарное переключение, проверка `release.txt` по HTTPS, откат, 10 выпусков). Настройки сервера: `/etc/travel-sites/tv.conf` (без сервиса аккаунтов), vhost `tv.proskurnin.com` с сертификатом Let's Encrypt.

Секреты репозитория: `DEPLOY_SSH_KEY`, `DEPLOY_KNOWN_HOSTS`. Ручной откат на сервере: `travel-site-deploy tv rollback`.

## Правила

- На сайт попадает только то, что можно публиковать: снимки проходят правила docs/SCREENSHOTS.md, в текстах нет адресов домашней сети, маршрутов API и личных данных.
- Новая возможность лаунчера, видимая пользователю, — повод добавить или поправить плитку в `site/index.html` и её перевод в `site/assets/app.js`.
- Подвал всегда содержит «made with ♥ by Roman A. Proskurnin» и атрибуцию текущего фона.
