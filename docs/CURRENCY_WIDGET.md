# Настраиваемый виджет валют — 1.42

Оформление экрана → «Виджет валют» (Sber, также доступно через Menu); на Universal — последний пункт основных настроек.

- До четырёх строк, любое количество от0 до4. При уменьшении количества нижний край блока сохраняется; все строки76px, промежутки11px.
- Доступны USD, EUR, CNY, GBP, CHF, JPY, AED, RUB, BTC, ETH, SOL. Для каждой строки котировка в RUB/USD/EUR, кроме пары валюты с самой собой.
- Выбор строки открывает замену валюты, котировку, перемещение выше/ниже и удаление. Дубли одной пары запрещены. «Добавить» ограничено четырьмя строками.
- Выключатели виджета и графиков; сброс возвращает USD/RUB, EUR/RUB, CNY/RUB, BTC/USD и включает графики/виджет.
- Круги символов имеют непрозрачность191/255 (~75%). Общий фон строк совпадает с верхними кнопками.

## Данные

USD/EUR/CNY в RUB используют прежний ЦБ с резервом Coinbase; остальные пары — публичный Coinbase без ключа. [Текущие курсы](https://docs.cdp.coinbase.com/coinbase-app/track-apis/exchange-rates), [цены и история](https://docs.cdp.coinbase.com/coinbase-app/track-apis/prices). Котировки справочные, не предложение обмена.

Кэш разделён по паре и источнику; данные/история прежних четырёх строк переносятся. Источники никогда не смешиваются при расчёте динамики. День сравнения UTC, история6 предыдущих дат плюс актуальный курс. Если API не отдаёт пару или историю, остаются кэш/прочерки и пропуски графика. Доступность всех исторических пар не гарантируется.

Основные фиатные пары обновляются раз6часов, остальные раз5минут только на видимом Home. Повтор неудачной истории не чаще30минут; дата/источник входят в ключ. История старше8дней удаляется. После ухода/выключения виджета новые запросы не начинаются, текущий ограничен таймаутами сетевого клиента. Отказ одного инструмента не стирает его кэш и не блокирует главный поток. Кэш старше7дней не показывается как текущая цена. Для цен ниже1 выводятся4знака и соответствующая точность динамики; нулевое округлённое изменение — нейтральное тире.

## Проверки и откат

CurrencyConfigTest проверяет исходный набор, пустой список, некорректные/одинаковые пары, лимит, изоляцию ключей источника/котировки и малую динамику. Обе сборки проходят проверки переносимого комплекта. Аппаратный результат фиксируется в CHANGELOG.md; Xiaomi отложен владельцем.

Отключение: «Виджет валют» → «Виджет: выкл». Возврат исходного набора — «Сбросить». Предыдущий APK Sber1.41.3 сохранён локально в backups/currency-widget-before-142/; для возврата к прежнему коду без удаления данных нужна сборка старых исходников с новым versionCode и тем же ключом. Ключи API и системные настройки для виджета не меняются.
