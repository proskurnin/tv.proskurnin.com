# Приложения, порядок и папка «Прочее»

Доступно с Proskurnin TV 1.33; текущая версия 1.34.2 (code 43).

## Управление пультом

- Удерживать OK на приложении → контекстное меню. Работает на главном экране, в нижнем списке и внутри «Прочего».
- «Переместить» → стрелками выбрать положение → OK сохранить, Back отменить. Зелёная рамка означает режим перемещения. Остальные плитки сдвигаются; размер плитки не меняется. Уход из лаунчера отменяет незавершённое перемещение.
- «В папку „Прочее“» убирает приложение из обычных списков. Приложение остаётся установленным и работает. Для главного экрана сначала выбирается замена из нижнего списка либо «Без замены».
- «На главный экран» добавляет в конец свободного ряда. Если все шесть мест заняты, необходимо явно выбрать заменяемое приложение. Оно переходит в нижний список. У приложения, уже находящегося на главном экране, вместо этой команды есть «Заменить приложение».
- «Убрать с главного экрана» возвращает приложение в нижний список без помещения в папку.
- Внутри папки: «Вернуть в список приложений» либо «На главный экран».

«Прочее» всегда последняя плитка нижнего списка, включая пустую папку. Переместить саму папку нельзя. Back возвращает из папки к её плитке, затем на главный экран. Сортировка внутри папки также сохраняется.

Главный ряд содержит максимум шесть приложений. Ряд из 1–5 плиток центрируется горизонтально. Можно убрать все приложения: останется подсказка перехода вниз, откуда их можно вернуть. Порядок сохраняется по package name, независимо от локализованного названия. Новые установленные приложения добавляются в конец нижнего списка перед папкой; удалённые исключаются после обновления списка.

В 1.33.1 все три списка используют одну операцию перестановки. На главном экране: **долгий OK → Переместить → ← / → → OK**. Back отменяет. Отпускание OK из закрытого меню без нового нажатия в основном экране игнорируется, чтобы случайно не завершить режим перемещения.

На Home подсказка: «Долгий ОК — Вспомогательное меню». Пункт «Переместить» остаётся внутри этого меню.

## Диалоги в 1.34

Меню долгого OK, выбор/замена приложений, настройки и подтверждения самого лаунчера используют однотонное тёмное окно со скруглением и голубым выделением. Списки сохраняют нативную навигацию пультом, прокрутку и Back. Первым фокус получает список; у выбора с отметками сохраняется выбранный пункт. Системное меню Power и окна сторонних приложений принадлежат другим процессам и этим оформлением не заменяются.

## Внешний вид

С 1.38 плитки всех трёх списков имеют пропорции 16:9. Приоритет: баннер стартовой Activity (сначала выбирается LEANBACK_LAUNCHER), затем общий `android:banner` приложения, затем обычная иконка. Баннер из APK заполняет плитку; изображение с нестандартными пропорциями вписывается целиком на нейтральном фоне без растяжения и обрезки логотипа. Внешние углы скруглены одинаково, рамка фокуса рисуется поверх. Подпись под плиткой сохранена.

С 1.38.1 у каждой плитки есть постоянный тонкий серо-белый контур: 2 пикселя в макете 1920×1080, около 19% непрозрачности. Он расположен внутри границы со скруглением, применяется также к резервным иконкам и папке «Прочее» и отделяет тёмные баннеры от фона. Выбранная плитка дополнительно получает прежнюю яркую внешнюю рамку; в режиме перемещения она зелёная. Изображения баннеров не перекрашиваются, градиенты и тени не добавляются.

При отсутствии баннера остаётся квадратная иконка с маской скругления на подложке: 80% тёмной основы и 20% преобладающего цветного оттенка иконки. Для нейтральных иконок используется серый цвет. Лаунчер не добавляет градиенты; собственные цвета и градиенты баннера не изменяются.

Баннеры читаются локально без сети, в фоновом потоке. Подготовленная копия ограничена 320×180 (иконка — 144×144), повторно используется и обновляется при изменении пакета/Activity/конфигурации ресурсов. Пиксели не анализируются в onDraw. Удалённые пакеты исключаются из кэша при обновлении списка.

Выключение цвета: **Настройки → Оформление экрана → Цветные подложки приложений**. Настройка касается резервных плиток с иконкой; фирменный баннер не перекрашивается. Скругление остаётся единым.

## Хранение и возврат

Новый порядок хранится в `preview/app_arrangement_v1`: `home`, `apps`, `other`. Исходная настройка `favorites` сохранена без изменений; её дополнительная копия создаётся в `favorites_before_arrangement`. Эти данные находятся в приватных настройках приложения и не публикуются.

Резервный APK до обновления: локальный `reports/app-layout-v133/previous-1.32.2.apk`. Возврат при необходимости:

```sh
adb -s <ТВ>:5555 install -r -d reports/app-layout-v133/previous-1.32.2.apk
adb -s <ТВ>:5555 shell am start -n local.proskurnin.preview/.MainActivity
```

Старая версия использует сохранённую исходную шестёрку, игнорируя новый порядок. Данные приложения не очищать. На некоторых сборках Android downgrade может быть запрещён; тогда остановиться, не удалять приложение ради обхода. Версия 1.33 при повторной установке вновь прочитает свой сохранённый порядок.

## Проверено

1.33.1: тесты рядов 1–6 и общих перестановок; на ТВ через ADB меню главного ряда, сдвиг вправо, сохранение, отмена и обратное перемещение. Исходный порядок восстановлен. Физический пульт ещё требует пользовательской проверки.


- Java-тест: заполненные шесть мест, явная замена, отправка в папку с заменой/без неё, возврат, пустой главный ряд, удаление/добавление пакетов, отсутствие дублей, копия для отмены, границы навигации, центрирование; 2000 смешанных операций сохраняют инварианты.
- Сборка и подпись APK для API 28; установка на ТВ Android 9, 1920×1080.
- Через ADB на настоящем ТВ: меню долгого OK; перемещение главного и нижнего списков; перенос Кинопоиска в папку и возврат; центрированный ряд из пяти плиток; выбор заменяемого из шести; сохранение нижнего порядка после остановки и повторного запуска процесса; запуск Okko и возврат Home. После теста исходный порядок восстановлен, папка оставлена пустой.
- По одному итоговому замеру PSS лаунчера около 37 МиБ; в просмотренном журнале AndroidRuntime ошибок нет. Это не длительный замер плавности.
- `am force-stop` на этой прошивке удаляет службу приложения из enabled_accessibility_services. После теста восстановлена ранее включённая VoiceKeyService с сохранением TextInputService; наличие обеих привязанных служб подтверждено dumpsys accessibility. При будущих тестах заранее сохранять список служб. Не использовать force-stop как обычный способ выхода.
- Физическое удержание OK, длительная эксплуатация и сохранение после перезагрузки ТВ требуют пользовательской проверки. Перезагрузка ТВ в рамках выпуска не выполнялась.
