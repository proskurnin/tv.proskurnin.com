# Приёмка Universal на новом телевизоре

Дата подготовки: 2026-11-09. Физические пункты ниже **не выполнены для новой Universal 1.40**; прежние тесты Sber/Xiaomi не заменяют их. Не отмечать по наличию APK или успеху сборки.

## Локально проверено

- Сборка APK лаунчера и пульта и DEX помощника, проверка подписей.
- Manifest Universal не содержит BootHomeReceiver и PowerMenuActivity; сохраняет AI, DreamService и защищённый provider.
- HTTPS-конфигурация: отказ HTTP, userinfo, query, fragment, чужим путям; отдельные токены, приватные файлы, отказ symlink.
- Backend запускается на loopback; неверный токен → 401, неизвестные операции → 404, API-токен не подходит к погоде. Тесты не вызывают платных внешних API.
- Контракты AI/фильмов/транскрипции и прежнего Xiaomi-профиля проходят автоматические тесты.
- Архив собирается по списку разрешённых исходников, проверяются контрольные суммы, подписи и отсутствие приватных файлов/известных токенов.

Точный вывод проверок и версии инструментов — BUILD-INFO.txt в пакете. Сборка исходников не обязана быть побитово одинаковой: ZIP/APK имеют времена, подпись, локальный ключ. Повторяемый процесс не означает воспроизводимые байт-в-байт бинарники.

## Карточка устройства (хранить локально)

- Производитель/модель, build fingerprint, Android/API/ABI, RAM и свободное место.
- Разрешение UI/панели, частота, плотность; способ управления пультом.
- Исходные Home/DreamService/VoiceInteractionService; сохранённый предыдущий APK.
- HDMI/Live TV, CEC, Bluetooth-пульт/аудио, доступность микрофона.
- Без серийного номера, MAC, токенов или текстов личных запросов в публичном отчёте.

## Физическая проверка

- [ ] Обычный запуск, холодный старт приложения, все стрелки/OK/Back, отсутствие белой вспышки.
- [ ] Полный список приложений, запуск нужных кинотеатров и возврат, TV-баннеры и резервные иконки.
- [ ] Перенос между главным/нижним списком/«Прочее», отмена и сохранение порядка.
- [ ] Офлайн-часы/фон, смена времени суток, актуальность погоды, резерв/ошибки поставщиков.
- [ ] YouTube с новым токеном, дневная динамика только при наличии истории; курсы и графики.
- [ ] AI-фильм/обычный диалог, веб-поиск вкл/выкл, озвучка, отмена, длинные названия, голос/текст.
- [ ] Штатный голос до/после; опциональный перехват включать отдельно, при двойном запуске выключить последнюю службу.
- [ ] HDMI/Live TV и звук, Bluetooth/громкость/CEC не изменились.
- [ ] Пульт: код, подтверждение/отказ, повторное подключение, чужая подсеть/неверный код не получают доступ.
- [ ] Без bridge: наш главный экран, громкость, доступность в нескольких приложениях; неподдерживаемый Canvas возвращает отказ, не ложный успех.
- [ ] При необходимости bridge: правильная подпись, shell UID, запрет чужому APK и остановка процесса.
- [ ] HTTPS на настоящих iPhone и Android, микрофон телефона, текст/кириллица, отказ для пароля, смена поля.
- [ ] Полное выключение сервера и очистка сопряжений по отдельному явному действию.
- [ ] Системная заставка: 5 загруженных роликов, нет сети, медленная сеть, лимиты, пульт/выход, прежнее приложение.
- [ ] Память/плавность после длительного использования, прекращение фоновой перерисовки при уходе.
- [ ] После успешного Preview выбрать Home вручную; холодная загрузка, сон/пробуждение, один согласованный перезапуск, возврат штатного Home.

Если ADB запрещён/нестабилен, записать результат и остановиться. Не менять загрузчик/пакеты ради прохождения чек-листа. Установка новой сборки, выбор Home, перезагрузка и удаление данных — разные действия, не считать их автоматически проверенными вместе.
