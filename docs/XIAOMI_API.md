## Подключение API без root

Раньше конфигурация Sber записывалась привилегированным скриптом. На Xiaomi этот скрипт **не применять**.

Новый `PreviewApiConfigProvider` принимает только `configure`/`status`, только от UID shell 2000, с объявленным `android.permission.DUMP`. У него нет чтения содержимого, произвольных путей, команд или сетевых URL. Другим приложениям импорт недоступен; поведение на реальном Xiaomi ещё не проверено. При отказе Android остановиться, не выдавать дополнительные права и не пробовать root.

Скрипт `scripts/provision-xiaomi-preview-api.py` читает приватный файл владельца, максимум 1024 байта, без symlink, запрещает права для группы/остальных. Допустимы только version=1, отдельные api_token/weather_token (не ключи поставщиков). Данные проходят через stdin авторизованного ADB shell в свой ContentProvider. Ничего не пишется в Download/sdcard, секреты не выводятся в чат/журнал/аргументы процесса adb на Mac. Владелец привилегированного shell в момент импорта имеет этот доступ — защита не рассчитана на скомпрометированный Mac/ADB.

Приложение атомарно сохраняет один файл в собственном sandbox, с восстановлением AtomicFile при прерванной записи. Фиксированный HTTPS endpoint — существующий RU API. Погода идёт через RU с прямым резервом для каждого поставщика; ключи погодных поставщиков не нужны. Upstream-ключи OpenAI/Google/TMDB и OAuth остаются на сервере. Сертификат локального веб-пульта и пары телефонов не копируются.

Для Xiaomi зарегистрирован независимый доступ `tv-xiaomi-nino`. Прежний `tv-sdx43` сохранён. Локальный файл — игнорируемый `integrations/server/private/xiaomi-preview-api.json`, режим 0600; не включать его в APK/Git и не присылать в чат. AI-лимиты существующего US worker остаются общими, отдельный доступ не означает отдельную квоту.

## Оставшиеся действия после восстановления связи

1. Подтвердить адрес/модель, доступность ADB и установленную версию; закрытый keylayout не читать. При отказе или offline остановиться.
2. Сверить SHA256 APK и обновить поверх:

```sh
adb -P 5038 -s 192.168.18.144:5555 install -r builds/proskurnin-preview-v1/ProskurninXiaomiPreview.apk
```

3. Передать отдельную конфигурацию (ключи поставщиков не запрашивать):

```sh
python3 scripts/provision-xiaomi-preview-api.py --adb-server-port 5038 --device 192.168.18.144:5555 --config integrations/server/private/xiaomi-preview-api.json
```

4. Открыть MainActivity, проверить счётчик, обновление погоды, три карточки фильма, AI-диалог/звук, ручной голос/Back. Разрешение микрофона — через обычный диалог Android. Проверить, что Home, Dream, Katniss и ранее активные accessibility не изменились. Не считать успешный запрос с Mac доказательством работы ТВ.

## Выключение и откат

- YouTube: настройки → «Счётчик YouTube» → выключить. Значок AI: настройки → «Значок AI» → выключить. Доступ к самим AI-экранам через настройки сохраняется.
- Выход в штатный экран — Home. Удаление только Preview: Android → Приложения → Proskurnin TV · Preview → Удалить, либо `adb -P 5038 -s 192.168.18.144:5555 uninstall local.proskurnin.xiaomipreview` (удалит его частные настройки/доступ).
- Отзыв только Xiaomi: убрать `tv-xiaomi-nino` из `device_auth_hashes` в `/etc/proskurnin-api/relay.json` и `device_token_hashes` в `/etc/proskurnin-api/weather.json`, перезапустить только `proskurnin-api-relay` и `proskurnin-weather-api`. Прежние поля доступа Sber не трогать. После отзыва очистить приватный локальный файл Xiaomi, если больше не нужен.
- Резерв RU: `/var/backups/proskurnin-api/20261109T113845Z-xiaomi-api`. Полный откат этого обновления сервера — вернуть оттуда api_relay.py/weather_gateway.py в `/opt/proskurnin-api/`, relay.json/weather.json в `/etc/proskurnin-api/` с сохранением владельца/прав и перезапустить указанные два сервиса. Дополнительный device_auth.py после возврата старого кода не используется. Такой откат уберёт доступ Xiaomi, сохранив исходный Sber.
- Предыдущий APK 1.39.1: `reports/xiaomi-preview-v1391/ProskurninXiaomiPreview-1.39.1.apk`. Для сохранения данных при запрете downgrade пересобрать предыдущие исходники с большим versionCode и прежней подписью; не очищать данные остальных приложений.
