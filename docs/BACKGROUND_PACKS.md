# Фоны по времени суток

## Предпросмотр — 2026-11-09

Подготовлены два набора по четыре реальные фотографии: «Горы и озёра» и «Море». Это локальные дизайн-макеты, не обновление APK и не установка на телевизор.

Локальная папка: `reports/background-concepts-v1/` (не публикуется в Git).

- `index.html` — автономная галерея: набор, утро/день/вечер/ночь, затемнение, скрытие интерфейса, полный экран.
- `01-mountains-overview.jpg`, `02-sea-overview.jpg` — обзорные листы.
- `mockups/` — восемь PNG 1920×1080 с компоновкой текущего лаунчера. Это HTML-реконструкция, метрики шрифтов отличаются от Android; баннеры взяты из существующего контрольного снимка. Виджеты содержат иллюстративные данные, не новые измерения.
- `photos/` — неизменённые скачанные JPEG шириной 1920 px, вместе 4 776 337 байт. Это копии для сравнения, не оригиналы 4K.
- `SOURCES.md`, `sources.json`, `manifest.json` — авторы, страницы Commons, лицензии, исходные размеры и SHA256 скачанных файлов.

Фотографии имеют лицензии CC BY 4.0 / CC BY-SA 3.0 / CC BY-SA 4.0; это не набор CC0. Перед распространением сохранить атрибуцию и условия ShareAlike для адаптированных изображений. Утренний морской исходник 3757×2500: он не обеспечивает честные 3840 пикселей по ширине, для полного 4K нужен другой кадр. Остальные исходники имеют достаточные размеры для центрального кадрирования 16:9 до 3840×2160, но качество требует отдельной проверки оригиналов.

Общий уровень затемнения макетов — 69%, без добавленных градиентов и анимации. В галерее его можно менять. Переходы цвета внутри самих фотографий естественные; отсутствие полос на панели требует проверки на ТВ.

Проверено: открытие локально без внешних зависимостей; загрузка всех восьми кадров; выбор набора/периода, переключатель интерфейса, регулятор затемнения и масштабирование окна до 1280 px. Оба обзорных листа визуально просмотрены. ТВ, системное время и текущие фоны не менялись.

## Реализовано в 1.39 (code 51)

Настройки → Оформление экрана → Фон лаунчера. Также можно нажать MENU на главном экране и выбрать «Фон лаунчера».

- Выключатель изображения: однотонный тёмный фон.
- Три встроенных набора: прежние пейзажи, горы и озёра, море. Восемь новых JPEG добавляют около 4,8 МБ к ресурсам приложения. Все кадры доступны без сети, отдельной загрузки/API нет.
- Автоматическая смена по системному времени Android либо постоянное утро, день, вечер или ночь.
- Начало каждого периода задаётся с точностью до часа; интервалы сохраняют порядок утро → день → вечер → ночь. По умолчанию 06:00 / 11:00 / 17:00 / 22:00, ночь проходит через полночь. Системные часы и часовой пояс не меняются.
- Затемнение: 0 / 20 / 35 / 50 / 60 / 69 / 75 / 85%. Прежнее значение 69% сохранено.
- Плавная смена: 1,2 секунды, запрос кадров не чаще примерно 30 FPS; выключатель убирает переход. Постоянной анимации нет.
- Авторы и лицензии внутри настроек и в `app/assets/backgrounds/CREDITS.txt`; адаптации CC BY-SA сохраняют исходную лицензию.
- Кнопка возврата прежних фонов и всех настроек только этого раздела.

Фотографии декодируются последовательно в отдельном потоке; устаревшие задания игнорируются. Изображение обрезается по центру до 16:9 без растяжения. Декодирование ограничено 1920×1440 (для нынешнего Full HD UI), Bitmap ARGB8888. В норме отображается одна карта, в переходе — две; весь набор в RAM не держится. При ошибке нового кадра используется встроенный прежний пейзаж для периода, затем текущая карта/однотонный фон. При уходе из Home карты освобождаются для GC, отменяется применение результата и перерисовка перехода. Сетевых задач у фонов нет.

Проверка календарной логики: все часы стандартного расписания, изменённые границы, фиксированные периоды, полночь, недопустимые настройки и безопасные пути ресурсов — `tests/BackgroundConfigTest.java`.

На Sber через ADB проверены выбор обоих наборов, ручная ночь/автоматический день, выключатель, изменение расписания, затемнение, возврат Back в родительское меню и возврат из Xiaomi Home. PSS после возврата около 43,3 МиБ; это разовый замер. Службы accessibility/голоса и выбор системной заставки сохранены.

Отключение: «Фон лаунчера» → «Изображение» → выключено. Откат оформления: «Вернуть прежний фон и настройки». Откат APK: локальный `reports/background-settings-v139/launcher-1.38.1.apk`, без очистки данных; при запрете downgrade пересобрать прежние исходники с большим versionCode и той же подписью. Пульт и системные настройки не менять.

## Остаётся в плане

- Каталог скачиваемых наборов: миниатюры, точный размер, лицензии. В 1.39 есть только встроенные наборы, кнопки не имитируют скачивание.
- HTTPS-загрузка с ограничениями размера/разрешения, проверкой SHA256/декодирования, атомарным применением полного набора. Предложенный отдельный лимит 40 МБ должен учитывать временные файлы; не расходовать видеокэш 300 МБ.
- 4K-источники под подтверждённый 4K-режим; заменить утренний морской кадр с недостаточной шириной. Размер будущего 4K-пакета пока не измерен.
- Дополнительное расписание по местному восходу/закату; ручное расписание уже реализовано.
- Физическая проверка сна, холодного включения без сети и отсутствия полос на панели остаётся отдельно.
